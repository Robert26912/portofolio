01 — About

Bridging hardware and software

I'm an IoT engineer with a dual passion for embedded systems and building architecture. My background spans firmware development on ARM microcontrollers, Python backend services, and web-based dashboards for real-time data.

I approach every project with an architect's mindset — whether I'm designing a sensor network or a software system, I think about structure, modularity, and how the pieces connect.
